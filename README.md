# HTML Links and Navigation

## Explanation

This project demonstrates how to create and use hyperlinks in HTML. Links allow users to move between webpages, sections of the same page, websites, and email addresses.

## Problem Statement

Create an HTML webpage demonstrating different types of hyperlinks and navigation methods.

## Features

* External website links
* Internal page navigation
* Email link
* Link opening in a new tab
* Navigation menu

## How It Works

The `<a>` element is used to create hyperlinks.

The `href` attribute specifies the destination of a link.

The `target="_blank"` attribute opens a link in a new browser tab.

An internal link can navigate to a specific section using an element's `id`.

The `mailto:` scheme creates an email link.

## Technologies Used

* HTML5

## Program Flow

1. Open the webpage.
2. Display the navigation links.
3. Click the internal link to move to another section.
4. Click the external link to open another website.
5. Click the email link to open an email application.

## Sample Input

Links:

* Home
* About
* Google
* Contact

## Sample Output

A webpage containing different hyperlinks and navigation options.
